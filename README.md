# داشبورد سرمایه دانا — نسخه ۱۰

هدف: یک صفحه ساده برای تصمیم روزانه.

خروجی اصلی:
- تصمیم امروز: ورود پله‌ای / صبر / افران
- بهترین گزینه بین زر و فزر
- سرمایه، افق و هزینه جابه‌جایی
- امتیاز تکنیکال
- سناریوی ۳۰ روزه
- مزیت خالص نسبت به افران
- محدوده ورود، حد ضرر، مقاومت و R/R
- نمودار EMA20/50/200

رایگان و بدون API پولی.

اجرا:
pip install -r requirements.txt
streamlit run app.py
